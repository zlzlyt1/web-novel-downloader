## English

Download the Windows x64 installer and portable edition from [GitHub Releases](https://github.com/zlzlyt1/web-novel-downloader/releases). The installer creates shortcuts; the portable edition needs no installation. `SHA256SUMS.txt` verifies file integrity. Version 2.3.3 uses a two-stage nonlinear page animation: the old page sinks and fades, then the new page enters from the turn direction and settles into place.
