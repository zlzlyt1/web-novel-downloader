全网小说下载器 2.3.8（Windows x64）

文件说明
1. 全网小说下载器 Setup 2.3.8.exe
   安装版，可选择安装目录，并创建桌面与开始菜单快捷方式。

2. 全网小说下载器 2.3.8.exe
   便携版，无需安装，双击即可运行。

2.3.8 可选滚轮翻页
- “排版与翻页按键”新增“滚轮翻页”开关，默认关闭。
- 开启后仅在左右翻书模式响应纵向或横向滚轮，并通过间隔锁避免一次跳过多页。
- 设置面板自身仍可正常上下滚动，不会触发正文翻页。

2.3.7 设置面板完整显示
- 取消“排版与翻页按键”子面板的 500px 裁剪限制，底部按键项目可完整进入滚动区域。
- 设置面板固定在窗口可用高度内，支持独立上下滚动并预留滚动条空间。

2.3.6 动画关闭与章节衔接
- “翻页动画”增加“关闭动画”选项。
- 横向翻书按窗口页码计算当前位置，减少末页边界误差。
- 横向模式隐藏可能独占尾页的章节导航栏；正文最后一页继续下一页会直接进入下一章。

2.3.5 键盘动画与设置滚动
- 键盘翻页、自定义上一章/下一章、左右方向键切章和章节按钮统一使用当前翻页动画。
- 设置面板最大高度跟随窗口，内容较长时可在面板内部上下滚动。

2.3.4 翻页动画选择
- “排版与翻页按键”新增“翻页动画”，可在“下沉进入”和“惯性滑动”之间切换。
- 两套动画均保留非线性加速、减速、透明度和轻微模糊，并持久保存选择。

2.3.3 非线性翻页动画
- 旧页先向下沉降并淡出，新页再从翻页方向进入。
- 新页落位前带小幅回弹，位移、透明度和轻微模糊同步变化。
- 动画期间锁定重复触发，并继续遵守系统“减少动态效果”设置。

2.3.2 半透明翻页控件
- 左右翻书两侧按钮默认低透明度、浅阴影和细边框，减少对正文的遮挡。
- 鼠标悬停或键盘聚焦时按钮才恢复清晰显示。
- “排版与翻页按键”中可关闭侧边翻页按钮；关闭后仍可使用自定义按键翻页。

2.3.1 自定义按键扩展
- 左右翻书模式不再响应鼠标滚轮翻页。
- 自定义按键录入支持鼠标中键、左右侧键及其他鼠标按键。
- 新增上一章、下一章、字体放大和字体缩小四项可自定义按键，并自动避免重复绑定。

2.3.0 主题设置精简与展开箭头修复
- 主题只保留“功能颜色”，移除控件外框和填充颜色设置，控件恢复各主题默认配色。
- “排版与翻页按键”展开箭头使用居中的 SVG，收起和展开时均统一采用功能颜色。

2.2.9 翻页箭头对齐与颜色修复
- 左右翻页按钮改用居中的 SVG 箭头，消除字符字形造成的视觉偏移。
- 箭头和圆形外框均直接使用“功能颜色”。

2.2.8 功能颜色同步下载器
- 原“强调颜色”统一更名为“功能颜色”，与控件外框、控件填充并列显示。
- 功能颜色控制阅读器展开箭头、翻页箭头和选择状态，并同步控制下载器的主操作按钮。
- 外框、填充颜色同时适用于下载器全部常规按钮、输入框和选择框。

2.2.7 横向分页与自定义控件配色
- 横向翻书会优先保持完整段落、标题、引用、列表等内容块不跨页；超过单页高度的超长内容仍可正常阅读。
- 两侧圆形翻页按钮的 `<` / `>` 箭头改为水平、垂直居中。
- 阅读器“设置 → 主题”可展开选择浅色、羊皮纸、深色，并分别自定义控件外框、填充和强调色；重启后仍会保留。

2.2.6 左右翻页动画与悬浮按钮
- 左右翻书时正文带滑动动画。
- 页面两侧显示带圆形外边框及 `<` / `>` 箭头的自动隐藏翻页按钮。

2.2.5 动画设置面板
- 顶栏保留“打开 / 设置”，主题、翻页方式、格式转换、排版和按键均归入设置。
- 设置及其“排版与翻页按键”子区均支持展开/收起动画。

2.2.4 左右翻书模式
- 顶栏新增“上下 / 左右”翻页方式切换按钮。
- 左右模式按窗口自动分成书页，滚轮和自定义翻页键每次移动一页。
- 左右方向键恢复为章节切换。

2.2.3 左右方向键翻页
- 左右方向键可直接翻页，到章节边界自动切换章节。
- 原有翻页按键自定义和章节按钮继续保留。

2.2.2 翻页与按键自定义
- 默认使用 PageUp / PageDown 翻页，到章节边界自动切换章节。
- 在阅读器“排版”面板点击上一页键或下一页键后，按下任意按键即可更改。

2.2.1 长期阅读进度
- 当前章节和章内滚动位置写入 AppData，关闭、重启和升级便携版后仍能恢复。
- 旧版本地进度会自动迁移。

2.2.0 EPUB 阅读与格式转换
- 阅读器可打开 EPUB、Markdown、TXT，并识别 EPUB 目录和章节。
- 阅读器内可将当前书籍转换成另外两种格式，保留书名、章节和正文。

2.1.9 书架移除选项
- 使用跟随阅读器多主题的内置确认弹窗。
- 可仅移出书架，也可将小说及更新记录移入 Windows 回收站。

2.1.8 下载器手动章节更新
- 阅读器不再显示“更新”，更新入口移至下载器的“已下载书籍”。
- 每本书显示现有章数，可手动输入更大的目标章数并点击“追加”。
- 原有正文保持不变，只追加目标范围内尚未保存的章节并自动去重。

2.1.7 排版控制修复
- 修复字号、行距、段距和页边距数值显示滞后一拍的问题。
- 点击任意一行的加减按钮后，只会立即更新对应项目，不再看起来串行。

2.1.6 电脑窗口段落优化
- 将原来的“均衡”和“铺满”合并为一个“段落优化”开关。
- 自动把手机阅读器导出的逐句短段整理为适合电脑宽窗口的自然段。
- 保留章节标题、人物对话、发言提示、元数据和场景分隔，不插入无意义空格。
- 支持“001 标题”一类数字章节，并跳过正文前重复的数字目录。

2.1.4 书架、更新与去重
- 阅读器新增持久化书架，可直接打开或移除书架记录。
- 增量更新只追加新章节，保留现有正文。
- 重复下载按章节 ID 或 URL 去重，不覆盖同名不同来源的书。

2.1.1 排版修复
- “铺满”模式不再把多个语义段落强行合并。
- 移除用于拼接短段的双全角空格。
- 取消两端对齐造成的字间距和空格拉伸，改为自然换行。
- 清理中文字符之间，以及逗号、冒号、引号附近的异常空白。
- 铺满模式仍使用整个可用窗口宽度；均衡模式采用适中的居中行宽。
- 新增对话密集文本和硬换行残片的回归测试，全部四组测试通过。

安全提示
- 本版本未使用商业代码签名证书，Windows 可能显示“未知发布者”。
- 可使用同目录 SHA256SUMS.txt 核对文件完整性。
